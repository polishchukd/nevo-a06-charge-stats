# ChargeStats — Статистика зарядки Nevo A06

Автономное приложение для штатного головного устройства (ГУ) Changan Nevo A06. В фоне детектирует сессии зарядки, ведёт их историю и рассчитывает стоимость по вашему тарифу. Не требует интернета и внешнего железа.

---

## Возможности

- **Автоматическое обнаружение сессий** — приложение само определяет начало и конец зарядки (AC/DC), без участия пользователя.
- **История зарядок** — таблица с типом, датой, длительностью, мощностью, энергией, стоимостью и изменением SOC.
- **Живая строка** — активная сессия отображается первой с индикатором «идёт…», обновляется в реальном времени.
- **Расчёт стоимости** — по вашему тарифу (₽/кВт·ч) отдельно для AC и DC. Тарифы историчны: смена цены не меняет стоимость уже закрытых сессий.
- **Удаление сессий** — свайп строки влево.
- **Две темы** — светлая и тёмная (+ «как в системе»).
- **Два языка** — русский и английский (+ «как в системе»). Переключение без перезапуска.
- **Настройка видимости колонок** — скройте ненужные колонки таблицы.
- **Автозапуск после перезагрузки ГУ** — сервис возобновляется после `BOOT_COMPLETED`.

---

## Установка

Приложение подписано платформенным ключом и требует системного UID для доступа к VHAL.

```bash
# Сборка
cd app && ./build.sh

# Установка на ГУ (требуется root / системный доступ)
adb install -r dist/chargestats.apk
```

> ⚠️ Перед установкой убедитесь, что на ГУ есть возможность отката (`adb install -r` с предыдущей рабочей версией).

---

## Быстрый старт

1. **Установите** APK на ГУ.
2. **Запустите** приложение — иконка «Статистика зарядки».
3. **Настройте тарифы**: шестерёнка → «Стоимость электроэнергии» → введите цену за кВт·ч для AC и DC.
4. **Заряжайте** — приложение само откроет сессию при подключении пистолета и закроет после извлечения.

| Элемент                         | Описание                                |
|---------------------------------|-----------------------------------------|
| Сегмент «Месяц / Полгода / Год» | Фильтр истории по периоду               |
| Таблица сессий                  | Живая строка (активная) + история       |

## Как определяется сессия

| Событие     | Условие                                                               |
|-------------|-----------------------------------------------------------------------|
| Начало      | Статус зарядки = «идёт» + режим AC или DC, подтверждено 2 тика (~2 с) |
| Окончание   | Статус ≠ «идёт» в течение 5 с                                         |
| Устаревание | Нет обновления VHAL > 30 с → принудительное закрытие                  |
| Разрыв      | Пауза в данных > 60 с → закрытие + новая сессия                       |
| Фильтр шума | Энергия < 0.01 кВт·ч → сессия удаляется                               |

Тип зарядки определяется по явному сигналу режима из VHAL (AC = медленная, DC = быстрая).

## Структура данных (SQLite)

| Таблица    | Назначение                                                           |
|------------|----------------------------------------------------------------------|
| `sessions` | Одна строка на сессию: тип, время, энергия, мощность, SOC, стоимость |
| `samples`  | Сырые сэмплы 1 Гц (мощность, напряжение, ток, SOC)                   |
| `tariffs`  | История тарифов (цена + дата вступления)                             |
| `settings` | Ключ-значение: тема, язык, колонки, папка CSV, цены                  |

## Технические требования

- **Устройство**: штатная ГУ Changan Nevo A06, Android 14
- **Подпись**: платформенный ключ (`platform.pk8`)
- **minSdk**: 29 (Android 10)
- **Разрешения**: доступ к `CarPropertyManager` (VHAL), SAF для CSV
- **Интернет**: не требуется

---

## Безопасность

- Приложение **только читает** бортовые данные (VHAL), не пишет в свойства автомобиля.
- Не использует легаси-разрешения на внешнее хранилище — только SAF.
- Foreground-сервис с уведомлением низкого приоритета (не мешает штатной UI).
